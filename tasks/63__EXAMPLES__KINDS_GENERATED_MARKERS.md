# Examples for task 63

Examples with a command line are startup examples (AGENTS.md).

## Fixtures

### markers

```text tree
a.rs                       2026-10-01 10:00
b.rs                       2026-10-01 10:00
c.rs                       2026-10-01 10:00
```

File contents are in `tests/fixtures/markers/`: the first line of `a.rs` is `// @generated`, of `b.rs`
`// AUTOGEN: do not touch`; `c.rs` has no marker. Times are UTC.

## E63.1 The built-in markers

Fixture: `markers`

```

```

## E63.8 From the config file

Fixture: `markers`

```toml conf/k.toml
[kinds]
generated_markers = ["AUTOGEN"]
```

```text command
easy-peasy-mcp --config conf/k.toml
```

1. `get_config`

```json request get_config
{ "section": "kinds", "sources": true }
```

```text response
# easy-peasy-mcp <version>, spec 1, supported specs: 1
# read-only: server.allowed_roots, server.allow_update

[kinds]
generated_markers = ['AUTOGEN']    # file: conf/k.toml
generated_marker_lines = 5    # default
```

2. `find`

The config file itself has the marker in its first lines, so the query looks at Rust files only.

```json request
{"query": "kind = generated and name ~ '*.rs'"}
```

```text response
files: 1  lines: 0  matches: 0  result: r1
#1 kind = generated
#2 name ~ '*.rs'

./
b.rs  [#1 #2]
```
