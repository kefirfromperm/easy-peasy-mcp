### kinds

```text tree
app/README.md              2026-10-01 10:00
app/api.rs                 2026-10-01 10:00

app/data.csv               2026-10-01 10:00

app/notes_test.md          2026-10-01 10:00
app/schema.pb.go           2026-10-01 10:00
```

File contents are in `tests/fixtures/kinds/`. Times are UTC. The kinds by the built-in rules:

| File                  | Kind        | Rule                                                        |
|-----------------------|-------------|-------------------------------------------------------------|
| `app/api.rs`          | `generated` | the marker `Code generated by` in the first line            |
| `app/schema.pb.go`    | `generated` | `**/*.pb.go`                                                |
| `app/main_test.go`    | `test`      | `**/*_test.*`                                               |
| `app/notes_test.md`   | `test`      | `**/*_test.*`, before the `doc` rule `**/*.md`               |
| `app/README.md`       | `doc`       | `**/README*`                                                |
| `app/config.yaml`     | `config`    | `**/*.yaml`                                                 |
| `app/main.rs`         | `source`    | the language `rust` has `source = true`                     |
| `app/data.csv`        | `other`     | no rule                                                     |

Where an example returns files of several kinds, the files of the higher ranked kind (`source` > `test` > `config` >
`doc` > `generated` > `other`) come first in path order too.
