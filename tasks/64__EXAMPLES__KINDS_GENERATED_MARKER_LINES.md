# Examples for task 64

Examples with a command line are startup examples (AGENTS.md).

## Fixtures

### marker-lines

```text tree
late.rs                    2026-10-01 10:00
main.rs                    2026-10-01 10:00
```

File contents are in `tests/fixtures/marker-lines/`: `late.rs` has the marker `// @generated` on its third line,
`main.rs` has none. Times are UTC.
