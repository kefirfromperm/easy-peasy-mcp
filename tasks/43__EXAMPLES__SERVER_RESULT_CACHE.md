## E43.2 Turning the cache off and on

Without the cache a response has no result id; the ids count the kept results.

Fixture: `result-cache`

1. `find`

```json request
{ "query": "name = 'main.rs'" }
```

```text response
files: 1  lines: 0  matches: 0  result: r1
#1 name = 'main.rs'

src/
main.rs  [#1]
```

2. `update_config`

```json request update_config
{"set": "server.result_cache = 0"}
```

```text response
[server]
result_cache = 0    # was 50
```

3. `find`

```json request
{ "query": "name = 'main.rs'" }
```

```text response
files: 1  lines: 0  matches: 0
#1 name = 'main.rs'

src/
main.rs  [#1]
```

4. `update_config`

```json request update_config
{"reset": ["server.result_cache"]}
```

```text response
[server]
result_cache = 50    # was 0, reset
```

5. `find`

```json request
{ "query": "name = 'main.rs'" }
```

```text response
files: 1  lines: 0  matches: 0  result: r2
#1 name = 'main.rs'

src/
main.rs  [#1]
```
